Battle backgrounds. Drop a WebP image here with one of these names and battles there use it.
Until a file exists, the battle shows the drawn scene for that layer.

overworld-0.webp ... overworld-8.webp   Wild-area battles in that overworld layer (0 = Lumen Rest)
labyrinth-1.webp ... labyrinth-8.webp   Labyrinth floors leading down to that layer (1 = floors 1-5)
rift-1.webp ... rift-8.webp             Red Rift battles in that layer
dungeon.webp                           Dungeons you plan yourself in the Dungeon tab
battle.webp                            Any other battle, and the fallback under all of the above

Wide images work best (about 1600 x 640).
